# ФШ 777

Независимый локальный графический редактор: слои, текст, рисование, трансформации, стили и экспорт. Собственный интерфейс, Canvas-движок и текстурная проекция; без аккаунта, облачного сервера и исходников Adobe.

**Версия 0.7.1 — настольная тестовая версия, а не полная замена всем возможностям Photoshop.**

## Установить на Windows

Для запуска скачанного приложения аккаунт не требуется.

Открой **[Releases → ФШ 777](https://github.com/SSGSSBEx1080/NEUROHELL_NUMBER_1/releases)** и выбери:

- **`FSH777-0.7.1-Windows-x64.exe`** — установщик; создаёт ярлыки приложения.
- **`FSH777-0.7.1-Windows-x64.zip`** — версия без установки. Распакуй **всю** папку, затем запусти **`ФШ 777.exe`** внутри неё. Не перемещай один EXE отдельно от ресурсов.

Node.js, терминал, Arena и отдельно установленный браузер **не нужны**. После скачивания приложение работает офлайн. Целевая платформа — Windows x64; автоматическая проверка выполняется на `windows-latest` в GitHub Actions. ARM64, macOS и Linux-сборки пока не выпускаются.

Сборка **без цифровой подписи издателя**: Windows может показать SmartScreen/предупреждение о неизвестном издателе. Проверяй источник загрузки и SHA-256 из `SHA256SUMS.txt`; не отключай защиту системы. Эта версия не содержит автообновления.

Если выпуск ещё не опубликован, готовые CI-сборки доступны в **[Actions → Windows application](https://github.com/SSGSSBEx1080/NEUROHELL_NUMBER_1/actions/workflows/windows.yml)**: успешный запуск → Artifacts → `FSH777-Windows-x64`. Для загрузки артефактов нужен вход в GitHub; артефакты хранятся 30 дней.

## Первые действия

1. На главной выбери новый документ, открытие, демонстрацию или восстановление автокопии. Открой PNG/JPEG/WebP, PSD/PSB или старый `.777` через **Ctrl+O** либо перетащи файл в окно. Растровое изображение добавляется слоем на текущий холст. Новый холст — **Ctrl+N**.
2. Выбери слой на холсте или в правой панели. **V** — перемещение/трансформация, **T / Shift+T** — текст / рамка, **J** — восстановление области, **B/E** — кисть/ластик, **M** — прямоугольное выделение, **L** — лассо, **W** — палочка, **Q** — быстрая маска, **S** — штамп, **P/A** — перо/узлы, **G** — заливка/градиент. Правая кнопка или удержание открывает вертикальное подменю инструмента; Shift+буква переключает подтип.
3. **Ctrl+S сохраняет настоящий `.psd`**, не `.777`. Первый системный диалог выбирает путь, следующие Ctrl+S атомарно обновляют этот файл; «Файл → Сохранить PSD как…» выбирает другой. Веб-версия скачивает файл. **Ctrl+Shift+S** открывает экспорт PNG/JPG/WebP/PSD/PSB. В Windows появится обычный диалог выбора файла; уведомление «Файл сохранён» показывается после завершения записи.
4. До **6 вкладок** имеют отдельную историю; до **8 недавних проектов** хранятся локально и доступны на главной после перезапуска. «Автокопия сохранена» **не означает сохранение PSD на диск**. Профиль приложения и импортированные шрифты локальны; `.777` оставлен только как резервный формат.

- Общая панель «Тексты»: содержимое, метка, состояние, необязательные исходный текст/заметка, создание из слоя, связь и обмен.
- Рабочие среды «Стандартная», «Свойства», «Текстовые блоки»; прежняя геометрия панелей сохранена.

### Возможности 0.7 также включены

- **P / A — перо и редактор узлов**: кривые Безье, направляющие, добавление/удаление/сглаживание, несколько точек, соединение концов, компоненты и отверстия. Контур остаётся native PSD vector; Ctrl+Enter создаёт выделение.
- **15 корректирующих типов**: к набору 0.6 добавлены RGB-фотофильтр, карта градиента с 2–16 точками и Color Lookup/CUBE. Импорт/правка работают и без XMP; параметры не подменяются bitmap.
- **Переносимое цветовое оформление**: CUBE 2–33³, до 2 МиБ; загрузка/экспорт таблицы и экспорт верхнего глобального цветового стека в 17³/33³. Пространственные эффекты не отбрасываются молча.
- **Математика в числовых полях**: `1600/2`, `(40+12)*2`, `+=10`, `*=50%`, отмена Escape, ограничения без eval. Фокус не округляет точные данные; отменённые жесты не добавляют пустой undo.
- Надёжнее native photo-percent serialization и Windows font enumeration; сохранены границы текстовых глифов, маски, smart editing и прежние жесты.

Бинарные выпуски публикуются в Releases после проверки исходного приложения и упакованного EXE; старые версии не перезаписываются.

### Большой пакет 0.6 также включён

- **12 корректирующих слоёв**: уровни/кривые по RGB-каналам, экспозиция, HSL, vibrance, баланс цвета, Ч/Б, микшер, инверсия, постеризация, порог и legacy яркость/контраст. Настройки, opacity, маски и clipping остаются редактируемыми; PSD содержит native adjustment records.
- **Выделения** складываются, вычитаются и пересекаются. Палочка W, цветовой диапазон, расширение/сужение/граница/сглаживание/feather; рисуемая быстрая маска Q, загрузка alpha слоя. Undo/redo выделений сохраняется в живых вкладках.
- **Компоновка**: направляющие из линеек и px/%, native PSD guides, макеты колонок/полей, сетка, snapping, девять опорных точек холста, шесть выравниваний и четыре распределения нескольких слоёв.
- **Шесть растровых фильтров** с отменяемым worker и предпросмотром: unsharp, High Pass, медиана, шум, мозаика, Собель. Фильтр создаёт явную копию и сохраняет оригинал; это не подмена native Smart Filters.
- **Ctrl+F — поиск настоящих команд**, включая английские названия и неправильную раскладку. Ctrl+L/M/U открывают коррекции; Ctrl+I работает с активной маской. Инверсия/проявление/скрытие маски не растрируют текст или фигуру.

Подробный маршрут: [WORKFLOW](docs/WORKFLOW.md). Честная карта реализованного/частичного/отсутствующего: [FEATURE_MATRIX](docs/FEATURE_MATRIX.md). Все эти возможности — независимая реализация, не обещание 1:1 Adobe fidelity.

### Текстовые блоки

Вкладка **«Тексты»** хранит переиспользуемое содержимое, метки и заметки. Блок можно разместить на холсте или связать с существующим текстовым слоем; обновление выполняется явно по кнопке. Список сохраняется вместе с документом и экспортируется в `.777texts.json`. Прежние данные и настройки читаются с миграцией, не меняющей пользовательские тексты и связи.

### Знакомые жесты

| Действие                                  | Управление                          |
| ----------------------------------------- | ----------------------------------- |
| Копия слоя с перемещением                 | **Alt + перетаскивание**            |
| Пропорциональное масштабирование          | Тянуть угловой маркер **без Shift** |
| Свободное растяжение                      | **Shift + угловой маркер**          |
| Перспективное искажение                   | **Ctrl + угловой маркер**           |
| Скос                                      | **Ctrl + боковой маркер**           |
| Отмена жеста                              | **Esc**, пока кнопка мыши нажата    |
| Дублирование / отмена / повтор            | **Ctrl+J / Ctrl+Z / Ctrl+Shift+Z**  |
| Копирование/вставка слоя внутри редактора | **Ctrl+C / Ctrl+V**                 |
| Перемещение холста / вписать / 100%       | **Пробел + мышь / Ctrl+0 / Ctrl+1** |

Shift при **рисовании** фигуры задаёт квадрат/круг; Shift при **перемещении** ограничивает ось. Перспектива меняет реальные пиксели, но не уничтожает исходный текст/контур. Простые фигуры экспортируются векторными; проективный текст, деформированная обводка/эффекты и размытие используют стандартный смарт-объект с редактируемым вложенным PSD. Преобразования перечислены в **«Отчёте PSD»**. Текст редактируется в правой панели. Полный список клавиш — кнопка `?` в приложении.

## Что реализовано

- Растровые, текстовые и фигурные слои; настоящие группы и обтравка, видимость, блокировка, порядок, непрозрачность, 17 режимов наложения. Маски с кистью/плотностью/растушёвкой не уничтожают скрытые пиксели.
- Смарт-объект из слоя/группы, отдельная вкладка содержимого, атомарное применение с отменой; в PSD — placed layer и встроенный linked PSD. Поддерживаемые встроенные PSD открываются для редактирования и без собственного XMP.
- **Нативные векторные фигуры**: прямоугольник с четырьмя радиусами, эллипс, многоугольник, звезда, линия и рисование/редактирование поддерживаемых кривых Безье. Заливка, толщина/положение/штрихи/концы/стыки обводки, число сторон/лучей; undo и запись свойств.
- Перемещение, размер, поворот, отражение, проективное искажение и скос; история отмены. Перспектива использует WebGL, если он доступен, и CPU fallback — без двойного наложения полупрозрачных треугольников.
- Границы point text измеряются по реальным буквам, включая курсив, строки и трекинг; рамочный текст сохраняет рамку. Выделение, hit-test, маркеры, свойства и экспорт используют общую геометрию.
- Быстрый ввод текста на холсте, форматирование **справа**: шрифт, размер, начертание, цвет, трекинг, интерлиньяж, выравнивание. Системные Windows-шрифты, загрузка TTF/OTF и каталог 20 Google Fonts; 8 семейств доступны офлайн.
- Кисть, ластик, штамп, заливка, градиент, пипетка и HEX/RGB-палитра; прямоугольное выделение и свободное/многоугольное/магнитное лассо.
- Размер изображения/холста, рабочие меню, настройки темы/истории/автокопий/рендера; UI-пасхалки. RAF и кэширование неизменённого стека/эффектов.
- Цветокоррекция, инверсия, обесцвечивание; обводка, тень, внешнее свечение, цветовое/градиентное наложение.
- Удаление связанного фона по цвету краёв, волшебный ластик и заполнение выделения цветами окружения. **Это локальные алгоритмы, не нейросетевое/генеративное удаление.**
- Настоящая запись операций с паузой, восстановлением черновика, редактированием шагов и F-клавишами; атомарное воспроизведение с одной отменой. Безопасное **частичное** чтение `.atn`, JSON v1/v2.
- **J**: обводка → локальное восстановление бумаги/градиента/фактуры → предпросмотр и отдельный слой. Управляемые образцы, отменяемый worker, слой под верхним редактируемым текстом. Не генеративный ИИ.
- Прямоугольные/овальные текстовые рамки, автоподбор кегля, переносы и пресеты оформления. Текстовые блоки с метками/заметками связываются со слоями и сохраняются в PSD как дополнительные данные; сами слои остаются native type.
- Изменяемые док-панели справа/слева и плавающий док внутри окна, разделитель, три вкладки и среды «Стандартная», «Свойства», «Текстовые блоки». Положение сохраняется.
- PNG с прозрачностью или непрозрачным фоном, JPG с белой подложкой при прозрачном холсте, WebP, частичный слоистый PSD/PSB и собственный `.777`.

## Совместимость и пределы

**Перед обработкой важного PSD/PSB сделай копию оригинала.** Импорт создаёт рабочую копию и показывает отчёт о преобразованиях. PSD содержит обычные слои, native type/vector/adjustment data, маски, группы, направляющие и merged image; XMP только дополняет их. SHA-256 позволяет обнаружить внешнее изменение файла и не восстановить устаревший внутренний проект поверх новых native-данных; это не цифровая подпись. Без правок исходный файл в том же формате возвращается побайтно, пока доступен его локальный источник. **После редактирования нет гарантии обратимости всех Adobe-свойств.**

Подробная таблица: **[docs/COMPATIBILITY.md](docs/COMPATIBILITY.md)**.

Новые отдельные бюджеты: до 200 направляющих, до 8 образцов Color Range; растровые фильтры до 8 Мп / 20 секунд, изменение выделения до 4096² / 20 секунд.

Основные пределы: холст до **4096 × 4096**, до **100 слоёв**, **10–100 действий истории** (по умолчанию 50, с памятными бюджетами), **48 Мп** уникальных активных растров суммарно. PSD/PSB — RGB/градации серого, 8 бит; до 80 МБ файла и 192 МиБ декодированных данных. Наличие расширения PSB не снимает эти ограничения.

Нет RAW/CMYK/Lab/16–32 бит, полного Adobe color/FX/type engine, плагинов или гарантии идентичного цвета/типографики. ICC не применяется как полноценный рабочий color-managed процесс. Шрифты не встраиваются в PSD.

**Проверки:** набор из 265 unit, 11 desktop security/IPC/font-probe и 119 production browser scenarios. Независимый **psd-tools** проверяет 35 случаев: исходные Photoshop-authored MIT-фикстуры, растровые и векторные маски, нативные фигуры/текст, вложенные PSD и редактирование после удаления XMP со всех уровней. Дополнительно — корректирующие слои, комбинированные/быстрые маски, native guides и растровая фильтр-копия. Уровни, кривые, экспозиция, постеризация и инверсия в отдельных fixtures пересчитываются независимым ридером, не только читаются как кеши. Photo/GradientMap/CUBE дополнительно читаются как native descriptors и проверяются отдельной NumPy/SciPy-моделью, не Adobe-движком. Для растровых/текстовых/smart-композитов допуск ≤2/255 premultiplied RGBA; у независимо перерисованных векторных контуров отдельно учитывается различие сглаживания на геометрическом крае, не внутри фигуры. WebGL и принудительный CPU отдельно проверяются на сохранение alpha 128. **Сам XnConvert/Photoshop не запускался; 100% точности любых PSD не заявляется.** Перед выпуском Windows CI проверяет исходное приложение и упакованный EXE: повторный Ctrl+S, J/текстовые блоки/запись, измеренные границы, native type/vector и изменение вложенного PSD без XMP, а также поиск, native levels/curves/mask/guides, быструю маску, палочку и filter worker, P/A, выражения, Photo/GradientMap/CUBE I/O.

## Разработка

Требуется **Node.js 22.12+** и npm. Все команды — в корне репозитория.

```bash
npm ci
npm run desktop:dev          # сборка интерфейса и запуск Electron
```

Для веб-режима:

```bash
# При установке только веб-версии можно пропустить загрузку Electron:
ELECTRON_SKIP_BINARY_DOWNLOAD=1 npm ci   # Bash; в PowerShell задай $env:ELECTRON_SKIP_BINARY_DOWNLOAD='1'
npm run dev                 # 0.0.0.0:5173, подходит для Arena preview
```

`START-WINDOWS.bat` и `start.sh` — вспомогательные **Node/браузерные** запускатели, не готовые настольные приложения. После обновления исходников повтори `npm ci`. Если установка Electron была пропущена, перед `desktop:dev` убери переменную `ELECTRON_SKIP_BINARY_DOWNLOAD` и выполни `node node_modules/electron/install.js`.

```bash
npm run format:check        # единый читаемый стиль
npm run check               # TypeScript, включая referenced projects
npm test                    # unit-тесты движка/валидации/форматов
npm run test:desktop-security
npm run build               # production bundle + тексты лицензий
npm run test:e2e             # production-сборка, браузерные сценарии и пиксели экспорта
npm run test:desktop         # реальный Electron, запись файлов и PSD reimport
npm run desktop:windows     # на Windows: NSIS + ZIP в release/

# После полного test:e2e: независимый ридер (Python 3.11)
python -m venv .venv
.venv/bin/pip install -r tests/interop/requirements.txt
.venv/bin/python tests/interop/check_psd.py
# В Windows: .venv\Scripts\python.exe / pip.exe
```

В Linux браузерные тесты используют Chromium из npm. На других ОС сначала установи тестовый Chromium: `npx playwright install chromium`. Для Windows-пакета рекомендуемый путь — GitHub Actions: Linux-проверки → Windows-проверки → упаковка → запуск **упакованного** EXE → SHA-256/артефакты. Сборка Linux/macOS и кросс-сборка установщика не проверены.

`dist/`, `node_modules/`, `release/`, результаты тестов и исполняемые файлы не хранятся в Git. Настольный пакет содержит Electron/Chromium, локальные шрифты и интерфейс; ASAR не является шифрованием.

Модули, потоки данных, команды, ограничения и воспроизводимые проверки: **[docs/ARCHITECTURE.md](docs/ARCHITECTURE.md)**. Журнал обновления: [docs/UPDATE-0.7.1.md](docs/UPDATE-0.7.1.md).

### Выпуск

Push с маркером **`[windows-release]`** в сообщении коммита создаёт **черновик prerelease** `v<package.json version>` только после успешных Linux- и Windows-проверок. Существующий выпуск не перезаписывается. Публикация черновика выполняется отдельно после проверки результата; обычные push создают только CI-артефакты. Подробнее — `.github/workflows/windows.yml`.
