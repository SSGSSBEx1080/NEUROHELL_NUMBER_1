# Обновление 0.3 — журнал разработки

Это журнал исходного кода в рабочей ветке, **не объявление готовой Windows-сборки**. Опубликованная 0.2.0 пока не содержит этих изменений.

## Этап 1: PSD и ядро (1c6a716)

- Ctrl+S и обычное сохранение — настоящий PSD. Старый .777 остаётся отдельной резервной копией.
- Сохранение исходного файла без изменений — побайтовая передача; при совместимом изменении метаданных сохраняется исходная сжатая секция объединённых пикселей.
- Группы, маски, режимы наложения, эффекты и source-aware экспорт; собственные свойства дополнительно в ограниченном XMP.
- 3 Photoshop-authored MIT-фикстуры (группы / маски / эффекты): исходные байты, структура и объединённые пиксели после переименования проверены. Это **не доказательство полной совместимости Photoshop или XnConvert**.

## Этап 2: инструменты, текст и шрифты

- Вертикальные подтипы инструментов по ПКМ / удержанию 450 мс; Shift+буква перебирает подтипы.
- Свободное, прямолинейное и магнитное лассо; прямоугольное и овальное выделение. Магнитное лассо притягивается к локальному контрастному краю, не распознаёт объекты.
- Мягкая кисть, жёсткость / интервал / непрозрачность, ластик, штамп с Alt-источником текущего слоя, связная заливка цветом, линейный и радиальный градиент.
- Полигональная маска выделения ограничивает кисть / стирание / заливку. Растровые операции в worker, кодирование штриха после завершения, RAF и кэш нижнего стека.
- Текст редактируется в правой панели: содержание, семейство, размер, трекинг, интерлиньяж, цвет и начертания. Плавающего форматирования над холстом нет.
- 6 дополнительных встроенных OFL-семейств и каталог из 20 Google Fonts. Не встроенные шрифты загружаются **по нажатию** из официального google/fonts на GitHub вместе с лицензией; доступны ограничения сети / API.
- Локальные TTF/OTF, сохранение FontFace/IndexedDB; системные имена через разрешение браузера либо фиксированный Windows IPC-запрос без передачи команд из renderer. Шрифты автоматически не встраиваются в PSD.
- Настройки темы, истории, автосохранения, шахматной сетки, сглаживания и измерения времени кадра.

Проверки этапа: TypeScript / production build; 32 unit-теста; 28 браузерных сценариев (27 в общем прогоне, оставшийся после исправления UTF-8 locale headless Chromium — отдельно); 4 проверки desktop protocol/CSP/границы font IPC. Windows IPC и новые функции ещё не проверены в упакованном Windows-приложении.
