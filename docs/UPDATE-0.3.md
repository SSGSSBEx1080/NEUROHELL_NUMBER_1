# Обновление 0.3 — журнал разработки

Журнал изменения исходников 0.3.0. Бинарные сборки публикуются отдельно в GitHub Releases только после успешных Linux/Windows-проверок; старый выпуск 0.2.0 не заменяется.

## Этап 1: PSD и ядро (1c6a716)

- Ctrl+S и обычное сохранение — настоящий PSD. Старый .777 остаётся отдельной резервной копией.
- Сохранение исходного файла без изменений — побайтовая передача; при совместимом изменении метаданных сохраняется исходная сжатая секция объединённых пикселей.
- Группы, маски, режимы наложения, эффекты и source-aware экспорт; собственные свойства дополнительно в ограниченном XMP.
- 3 Photoshop-authored MIT-фикстуры (группы / маски / эффекты): исходные байты, структура и объединённые пиксели после переименования проверены. Это **не доказательство полной совместимости Photoshop или XnConvert**.

## Этап 2: инструменты, текст и шрифты

- Вертикальные подтипы инструментов по ПКМ / удержанию 450 мс; Shift+буква перебирает подтипы.
- Свободное, прямолинейное и магнитное лассо; прямоугольное и овальное выделение. Магнитное лассо притягивается к локальному контрастному краю, не распознаёт объекты.
- Мягкая кисть, жёсткость / интервал / непрозрачность, ластик, штамп с Alt-источником текущего слоя, связная заливка цветом, линейный и радиальный градиент.
- Полигональная маска выделения ограничивает кисть / стирание / заливку. Растровые операции в worker, кодирование штриха после завершения, RAF и кэш нижнего стека.
- Текст редактируется в правой панели: содержание, семейство, размер, трекинг, интерлиньяж, цвет и начертания. Плавающего форматирования над холстом нет.
- 6 дополнительных встроенных OFL-семейств и каталог из 20 Google Fonts. Не встроенные шрифты загружаются **по нажатию** из официального google/fonts на GitHub вместе с лицензией; доступны ограничения сети / API.
- Локальные TTF/OTF, сохранение FontFace/IndexedDB; системные имена через разрешение браузера либо фиксированный Windows IPC-запрос без передачи команд из renderer. Шрифты автоматически не встраиваются в PSD.
- Настройки темы, истории, автосохранения, шахматной сетки, сглаживания и измерения времени кадра.

Проверки этапа: TypeScript / production build; 32 unit-теста; 28 браузерных сценариев (27 в общем прогоне, оставшийся после исправления UTF-8 locale headless Chromium — отдельно); 4 проверки desktop protocol/CSP/границы font IPC. Windows IPC и новые функции ещё не проверены в упакованном Windows-приложении.

## Этап 3: рабочая среда и самостоятельное сохранение

- Главная, реальные недавние проекты с миниатюрами, явное предложение восстановления; до 6 вкладок с независимой историей. Закрытие не удаляет PSD на диске.
- Группы: сворачивание, Ctrl+клик для группировки нескольких слоёв, перемещение в группу, дублирование / удаление полного поддерева. Родительская блокировка применяется к содержимому.
- Создание / кисть / плотность / растушёвка / связь / отключение / удаление маски; обтравка по нижнему слою с общим альфа-каналом.
- Смарт-объекты создаются из слоя или группы, открываются отдельной вкладкой, применяются одним отменяемым действием. В PSD записывается настоящий placed/linked PSD, не только приватный XMP.
- Рабочие меню Изображение / Фильтры / Окно; размер изображения и холста; безопасные UI-пасхалки. Konami работает на главной, поэтому стрелки не сдвигают картинку.
- Windows-сохранение заменено с браузерного download на ограниченный IPC: пользователь выбирает путь, первый Ctrl+S запоминает его, следующий атомарно заменяет файл; Save As выбирает новый. Ошибка записи не обрезает существующий PSD. Renderer не передаёт произвольный путь.
- Исправлен реальный дефект PSD: повёрнутая маска ранее экспортировалась без её трансформации. Теперь экспорт сохраняет независимую редактируемую маску в координатах PSD. Для трансформированных масок плотность/растушёвка запекаются в native-mask, а исходные управляющие параметры остаются в XMP.
- Независимый psd-tools 1.25.0 проверяет объединённые пиксели **и заново собирает нативные слои**, не опираясь на наш XMP. Три собственных случая (поворот / отражение / перспектива маски): максимальная ошибка premultiplied RGBA менее 2 из 255. Это измеренная граница, **не 100%** и не запуск XnConvert.

## Стабилизация перед выпуском

- Исправлены стабильный порядок/названия вкладок и реальное применение **неактивного** смарт-содержимого из диалога закрытия. Родительские блокировки проверяются до применения.
- Время резервирования автокопии отделено от завершения миниатюры: поздний старый результат не затирает свежий документ. Проверено на fake-indexeddb. Очистка исходных PSD не удаляет источники недавних/вложенных документов; есть суточный защитный период для незавершённого импорта.
- Целевой общий бюджет истории вкладок; явное уведомление при сокращении неактивных undo-стеков. Это не лимит всей памяти процесса.
- Экспорт использует OpenType PostScript-имена, в том числе именованные начертания Manrope. Нет обещания поддержки всех variable-font осей или встраивания шрифтов.
- На appearance-preserving изменениях сохраняются неизвестные image resources/ICC, которых ag-psd сам не сериализует. Неизвестные layer blocks после правок всё ещё не гарантированы.
- Добавлены проверки отключённой и растушёванной повёрнутой маски; отключённая маска не меняет видимые source pixels при экспорте.
- Код, тесты и desktop-модули отформатированы; `check` теперь проверяет referenced TypeScript-проекты, а не пустой корневой tsconfig.

Итоговый локальный прогон 0.3.0: **43/43 unit, 7/7 desktop security/IPC, 39/39 production browser tests**, build/TypeScript, npm audit — 0 известных уязвимостей на момент проверки. Независимый Python-ридер прошёл все 8 фикстур: 3 исходных Photoshop + 5 собственных масок. На масках maximum premultiplied RGBA error: merged ≤1.946/255, native recomposition ≤1.538/255. Порог проверок — 2/255.

Windows source+packaged smoke промежуточного коммита `0f34a03` прошёл в запуске `39137935273`, в том числе перезапись PSD и список шрифтов. Выпуск 0.3.0 разрешён конвейером только после повторения полного набора проверок на release-коммите.

Оставшиеся ограничения: произвольные Adobe FX / ICC / векторные маски / корректирующие слои, 16/32-bit и CMYK не становятся полностью совместимыми от наличия ag-psd. Маски трансформированного растра сохраняют проверенный внешний вид, но Photoshop может по-другому пересчитать редактируемые эффекты и текст. Конкретный проблемный PSD от пользователя пока не получен.

Дополнительный браузерный smoke скачал настоящий Rubik из официального google/fonts (359804 байта), прочитал OFL и восстановил шрифт после reload из IndexedDB. В этой sandbox исходный сетевой запрос упирался в недоверенный TLS-сертификат перехватчика; проверка загрузки использовала только тестовый browser-context с trust override. **В приложении проверка сертификатов не отключается.** Обычная сетевая ошибка теперь выводится понятным русским сообщением с вариантом ручного TTF/OTF.

Последняя проверка перед публикацией нашла отдельный риск привязки файлов: копия, открытая после закрытия исходной вкладки, сохраняла импортированный document ID и могла унаследовать ранее одобренный Windows-путь. Новый регрессионный тест сначала воспроизвёл проблему. Теперь каждое открытие файла получает новый session ID; явное восстановление недавнего проекта остаётся отдельным путём. Windows smoke закрывает исходную вкладку, повторно открывает её PSD, требует **новый** SaveDialog для первого Ctrl+S и проверяет отсутствие повторного диалога для второго Ctrl+S. Непубликованный кандидат `930752a` заменяется проверенным исправлением, а не выдаётся за окончательный релиз.
