# ФШ777 ULTRA · 0.9 — добиваем честные границы 0.8

База — смердженная 0.8.0 (`main` 3cca307). Работа — в ветке Arena этого сеанса,
этапами с пушами после проверок; PR открывается из этой ветки, без авто-мержа.
Старые выпуски и профиль приложения не трогаем.

## Что осталось из честных границ 0.8 (UPDATE-0.8.md)

1. **Blend If** — диапазоны текущего/нижнего слоя с разделёнными порогами
   (серый + R/G/B). ag-psd нативно читает/пишет `blendingRanges`
   (quad `[blackLow, blackHigh, whiteLow, whiteHigh]`, дефолт `[0,0,255,255]`).
2. **Gradient-заливка обводки** — у ag-psd stroke есть
   `fillType: color|gradient|pattern` + нативный градиент-дескриптор.
3. **Формы градиентного наложения** — сейчас рендерится только linear;
   `LayerEffectGradientOverlay.type` поддерживает radial/angle/reflected/diamond.
4. **Pattern overlay** — нативный `patternOverlay` (scale/phase) у ag-psd есть;
   узоры нужны собственные процедурные.
5. **Bevel & Emboss** — нативный `LayerEffectBevel` у ag-psd есть; рендер —
   собственный алгоритм на поле расстояний и нормалях (без претензии на
   пересчёт Adobe, как и шум в 0.8).
6. **Satin** — нативный дескриптор есть; рендер собственный по документации
   поведения.
7. **Контуры эффектов** — `EffectContour` у ag-psd; объём после (1)-(6).
8. **Anti-aliasing как параметр текстового слоя** — Canvas2D не даёт управлять
   хинтингом; честно поддерживаемы «Нет» (порог alpha) и обычное сглаживание.
   Объём и границы фиксируем при реализации.
9. **Текст по контуру** — большой отдельный блок (раскладка + путь + PSD
   ограничения TySh у ag-psd). В этот круг не обещаем; фиксируем как остаток.

Порядок: 1 → 2+3 → 4 → 5 → 6 (8 по остатку). Каждый этап: типы → рендер →
PSD round-trip → UI → unit/e2e пиксельные проверки → коммит+push.

## Семантические решения, зафиксированные до кода

- Blend If считается по **итоговым пикселям слоя** (содержимое со стилями и
  маской) до его opacity/blendMode наложения; подложка — текущий композит под
  слоем в тех же координатах документа. Серый канал — яркость
  `0.3R + 0.59G + 0.11B`, округлённая до байта (LUT). Для корректирующих слоёв
  своих пикселей нет — работает только диапазон нижнего слоя как маска силы
  коррекции (явная граница).
- Никаких кнопок-пустышек: недоступное остаётся недоступным и подписанным.

## Состояние

Заполняется по мере этапов; готово только то, что прошло проверки и запушено.

1. **Blend If — готово.** `Layer.blendIf` (серый + R/G/B, разделённые пороги);
   движок `src/engine/blendIf.ts` (LUT, валидация для проектов/PSD/операций/
   библиотек); рендер — обёртка в `renderDocument` (слой плоско в поверхность,
   alpha модулируется по своим пикселям и снимку подложки; работает и как база
   clipping-стека) и under-маска силы в `renderCorrection` для корректирующих
   слоёв; нативный PSD round-trip `blendingRanges` (бинарный тест ag-psd);
   секция «Параметры наложения» в диалоге стилей, fx-метка в панели слоёв,
   копирование/вставка стиля переносит и диапазоны. Проверки: 304 unit
   (+5 Blend If), e2e: красная фигура скрывается по подложке и по собственной
   яркости, диапазоны находятся в записи слоя PSD без XMP.
