# ФШ777 · 0.6.0 Desktop — коррекции, выделения и компоновка

Крупный тестовый выпуск самостоятельного редактора **Windows x64**. Программа работает локально без Node.js, Arena, отдельного браузера или сервера. **Это не полная функциональная копия Photoshop и не обещание 1:1 Adobe fidelity.**

## Скачать и обновить

- **FSH777-0.6.0-Windows-x64.exe** — установщик.
- **FSH777-0.6.0-Windows-x64.zip** — распаковать **всю** папку, затем запустить `ФШ 777.exe`.
- **SHA256SUMS.txt** — SHA-256 обоих пакетов.

Репозиторий приватный: без входа в GitHub под аккаунтом с доступом ссылки могут показывать 404. Приватность не изменяется. Сборка не подписана издателем; проверяй источник/хеши и не отключай защиту Windows. Автообновления нет. Профиль приложения прежний; перед обновлением сохрани важные PSD и экспортируй операции. Выпуски 0.3–0.5 не переписываются.

## 12 корректирующих слоёв — не плоские картинки

- Яркость/контрастность (legacy), уровни, кривые, экспозиция, HSL, vibrance, цветовой баланс, Ч/Б по шести диапазонам, микшер каналов, инверсия, постеризация и порог.
- Отдельные RGB-каналы, интерактивная natural cubic кривая (до 16 точек, мышь/клавиатура), числовые параметры, пресеты и alpha-weighted гистограмма композита.
- Коррекции меняют нижний стек, учитывая opacity, blend, маску, clipping и изоляцию групп. Alpha исходного изображения не увеличивается. Выделение автоматически превращается в маску новой коррекции.
- PSD содержит настоящие adjustment records, не только XMP. Поддерживаемые внешние варианты можно редактировать без собственного проекта; параметры поддерживаются записью операций.

**Ctrl+L / Ctrl+M / Ctrl+U** создают неразрушающие уровни / кривые / HSL. Современный Adobe Light/CgEd и другие неизвестные варианты не подменяются упрощёнными ползунками молча. Legacy brightness записывает настоящий `brit`; независимый psd-tools классифицирует этот старый блок иначе, чем современные adjustments.

## Выделения и настоящая быстрая маска

- Новое / добавить / вычесть / пересечь: рамки, эллипс, лассо и новая палочка **W**. **Shift / Alt / Shift+Alt** задают режим до начала жеста. Старый волшебный ластик остаётся в группе **E**.
- Палочка выбирает смежные либо все подходящие цвета, из активного слоя или композита, **не стирая пиксели**.
- «Цветовой диапазон»: до 8 образцов, разброс, тени/средние тона/света, инверсия, предварительная маска. Это локальный RGB-алгоритм, не распознавание людей/объектов.
- Расширение/сужение, граница, сглаживание и растушёвка; обработка в отменяемом worker. Пустое пересечение не превращается в рисование по всему изображению.
- **Q**: B рисует покрытие (чёрный исключает, белый добавляет), E проявляет; работают мягкость и opacity. В исходное изображение рисунок быстрой маски не попадает.
- Выделения входят в undo/redo и живые вкладки. **Ctrl+Shift+D** — повторить; **Ctrl+Shift+I** — инверсия; Ctrl+клик миниатюры — alpha слоя.
- Обычные маски получили инверсию, проявление/скрытие всего и **Ctrl+I** в режиме маски, сохраняя TypeLayer/ShapeLayer.

Временные выделения **не заявляются native alpha channels** и не сохраняются после перезапуска. Применённая к слою маска сохраняется обычной структурой PSD. Только display-контур очень шумных масок может быть упрощён; реальные coverage bytes остаются полными.

## Направляющие, сетка и выравнивание

- Направляющие из линеек, точные px/%, перетаскивание, удаление за холст, lock/color/show, клавиатурные шаги. Положение и шаги сетки записываются в **native PSD resource 1032**, включая открытие без XMP.
- Генератор полей, колонок, строк и интервалов; пресеты третей/12 колонок. Сетка с независимыми X/Y и подразделениями.
- Snapping к guides/grid/слоям/границам и центру холста; Ctrl временно отключает привязку при перемещении. Это не меняет Ctrl-деформацию углов.
- Девять опорных точек размера холста, синхронный перенос направляющих и масок.
- Ctrl/Shift-мультивыбор для компоновки, шесть выравниваний и четыре распределения. Поддерево двигается один раз, замки проверяются заранее, одно undo. Общая свободная трансформация мультивыбора пока не добавлена.

**Ctrl+R** — линейки; **Ctrl+;** — guides; **Ctrl+'** — grid; **Ctrl+Shift+;** — snap. Разметка не попадает в пиксели. Перемещение направляющих не перерисовывает основной pixel-canvas.

## Фильтры на копии и поиск команд

- Unsharp / High Pass / weighted median / seed-based noise / mosaic / Sobel: реальные настройки, сравнение до/после и отменяемый worker. Source alpha сохраняется, невидимый RGB не загрязняет результат.
- Работают на исходном bitmap-разрешении с ограничением выделением. Геометрия, отражения, живые коррекции, маска и стили остаются на копии. Оригинал сохраняется и по умолчанию скрывается, чтобы не удвоить прозрачность.
- Это **явная растровая копия**, а не фиктивный native Smart Filter. Исходный smart object остаётся встроенным PSD. Текст/векторы галереей автоматически не растрируются.
- **Ctrl+F** ищет настоящие команды меню, инструменты и пользовательские операции; поддерживает английские aliases, неправильную раскладку, клавиатуру и recents. Недоступные команды не запускаются.

## Исправления ядра

- Metadata-only изменения внутри smart-content (например, имя слоя или guides) теперь обновляют linked PSD даже при прежнем preview.
- Экспозиция пересчитывается в приближённо линейном RGB (TRC≈2.2), кривые — natural cubic, постеризация — equal-width bins 2–255.
- Растеризация размытого изображения учитывает его ореол. Идентичный PNG больше не подменяет уже используемое кеш-представление и не меняет фильтрацию другого слоя.
- История учитывает bitmap-выделения в memory budgets. Неподдерживаемые записанные действия отмечаются явно, а не пропускаются.

Сохранены native type/vector/groups/masks/smart, измеренные text bounds, Ctrl+S → PSD, `.777` backup, J, рамки/сценарий, шрифты, док-панели, восстановление, GPU/CPU-перспектива и прежние Alt/Shift/Ctrl-жесты.

## Состав выпускных проверок

- **205 unit / 24 файла**, **7 security/IPC**, **101 production browser scenarios**.
- **29 независимых PSD-случаев**: исходники, type/vector/masks/embedded PSD, XMP-free edits, adjustments, selection masks, native guides и filter copy. Допуск растровых/текстовых/smart-композитов ≤2/255 premultiplied RGBA; для native-vector AA — отдельная ограниченная геометрическая полоса.
- Native levels/curves/exposure/posterize/invert пересчитываются psd-tools/SciPy на конкретных fixtures, включая alpha 128. Наличие других native records проверяется структурно. Type/smart-filter кеши не заменяют испытания Adobe-регенерации.
- Windows gate запускает исходный Electron и **упакованный EXE**, включая новые correction/mask/guide структуры, Q, W, command search и filter worker с сохранением оригинала.

**Photoshop/XnConvert и интерактивная установка NSIS отдельно не запускались.** Нет RAW/CMYK/Lab/16–32-bit/полного ICC, произвольных Adobe FX/filters/type, генеративного ИИ, полного pen/node editor, плагинов/видео/3D. Фильтры: до 8 Мп / 20 s; выделения: до 4096² / 20 s; guides до 200. Основные пределы: холст 4096², 100 слоёв, отдельные бюджеты памяти. Автокопия — не PSD на диске.
