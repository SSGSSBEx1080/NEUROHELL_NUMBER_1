# ФШ 777 · 0.2.0 Desktop

Самостоятельная тестовая сборка для Windows x64. Не требует Node.js, браузерного сервера или Arena. Интернет нужен для скачивания, но не для редактирования.

## Скачать и запустить

- `FSH777-0.2.0-Windows-x64.exe` — установщик с ярлыками.
- `FSH777-0.2.0-Windows-x64.zip` — распаковать целиком и запустить `ФШ 777.exe` внутри папки.
- `SHA256SUMS.txt` — контрольные суммы установщика и ZIP.

Сборка не подписана цифровым сертификатом: Windows может предупредить о неизвестном издателе. Проверяйте источник и контрольную сумму, не отключайте системную защиту.

## Основное

- Alt-перетаскивание дублирует слой одним отменяемым действием.
- Угловое масштабирование пропорционально без Shift; с Shift — свободно.
- Ctrl + угол меняет перспективу; Ctrl + боковой маркер выполняет скос. Изменяются реальные пиксели, а не только рамка.
- Локальные слои, текст с кириллицей, кисти/ластик, фигуры, выделение/кадрирование, цветокоррекция и базовые стили.
- Обычный Windows-диалог сохранения и уведомление после записи файла.
- PNG/JPG/WebP, редактируемый `.777`, частичный PSD/PSB и ограниченный безопасный ATN.

## Проверки сборки

Конвейер запускает TypeScript, unit/security-тесты, браузерные сценарии с проверкой пикселей и два нативных прогона: исходное приложение и **упакованный EXE**. Нативные тесты записывают на диск PNG/JPG/WebP/PSD/PSB/.777 и повторно открывают PSD. Это автоматизированная проверка в Windows CI, не обещание работы без ошибок на любой конфигурации.

## Перед работой

Сохраняйте `.777` через Ctrl+S — автосохранение хранит только последний проект. Не перезаписывайте единственный оригинальный PSD: импорт/экспорт частичный. Смарт-объекты, сложные маски/эффекты, исходные ICC-профили и некоторые текстовые свойства не сохраняются. До 4096 × 4096, 100 слоёв; действуют лимиты растровой памяти. Удаление фона/заливка локальные, не нейросетевые. Полные ограничения описаны в README и `docs/COMPATIBILITY.md`.
