# ФШ777 · 0.3.0 Desktop

Крупное обновление самостоятельного редактора для **Windows x64**. Node.js, Arena и браузерный сервер для запуска не нужны. Это тестовый prerelease, не полная замена Photoshop и не гарантия конвертации любых PSD.

## Скачать

- **FSH777-0.3.0-Windows-x64.exe** — установщик.
- **FSH777-0.3.0-Windows-x64.zip** — распаковать **всю** папку и запустить `ФШ 777.exe`.
- **SHA256SUMS.txt** — контрольные суммы файлов.

Цифровой подписи издателя нет. Windows может показать предупреждение; проверяй источник и SHA-256, не отключай защиту системы. Автообновления нет: 0.3.0 устанавливается отдельно от скачивания старой 0.2.0, профиль приложения используется прежний.

## Главное

- **Ctrl+S → настоящий PSD**, а не `.777`. В Windows первый выбор пути запоминается; повторная запись атомарная. «Сохранить PSD как…» выбирает новый файл. Исходник при открытии автоматически не перезаписывается.
- Native layers/groups/masks, blend/opacity/transparency, настоящий merged image; собственный XMP добавлен для редактируемости ФШ777, не вместо PSD.
- Исправлены координаты трансформированных масок при экспорте. Неизменённый импортированный PSD сохраняется побайтно в том же формате; некоторые неизвестные ресурсы, включая ICC, сохраняются и после невизуальных изменений.
- Главная, недавние проекты, явное восстановление автокопий; до 6 вкладок с отдельной историей.
- Группы, обтравка, кисть по маске, плотность/растушёвка/связь; создание и отдельное редактирование смарт-содержимого, embedded linked PSD.
- Свободное / многоугольное / магнитное лассо, прямоугольное выделение; вертикальные подменю инструментов по правой кнопке или удержанию. Кисть, ластик, штамп, пипетка, заливка, градиент и фигуры.
- Форматирование текста справа; системные Windows-шрифты, TTF/OTF, 20 выбранных Google-семейств. Восемь семейств доступны офлайн; остальные требуют интернета.
- Размер изображения/холста, рабочие меню и настройки тем/истории/автосохранения/производительности, UI-пасхалки.
- RAF-отрисовка, кэш нижнего стека/изображений/эффектов, ограничение групповых поверхностей и истории.

Знакомые жесты сохранены: **Alt+drag — копия; угол без Shift — пропорционально; Shift — свободное растяжение; Ctrl+угол — перспектива, Ctrl+бок — скос.**

## Проверки и границы

Конвейер перед выпуском проверяет TypeScript, unit/IPC/security, production browser scenarios, независимое чтение PSD через psd-tools, Windows source smoke и **упакованный EXE**. Windows smoke записывает PNG/JPG/WebP/PSD/PSB/backup, повторяет Ctrl+S и повторно открывает PSD.

Три Photoshop-authored MIT-фикстуры проверяют побайтное сохранение/неизменность композита. Пять собственных случаев масок сравнивают PNG с merged image и заново собранными native layers: допустимая максимальная ошибка premultiplied RGBA — 2/255.

**Сам XnConvert/Photoshop не запускался. 100% точности произвольных PSD не заявляется.** Сложные Adobe FX, ICC-конверсия, векторные/real-маски, корректирующие слои и типографика остаются частично совместимыми. Шрифты не встраиваются в PSD; для редактирования на другом ПК нужны те же файлы шрифтов. До 4096 × 4096, 100 слоёв; есть файловые/памятные бюджеты. Удаление фона/заливка не нейросетевые.

Сохраняй важный оригинал отдельно. «Автокопия сохранена» относится к локальному профилю, **не к PSD на диске**. Подробная таблица совместимости и воспроизводимые проверки — `docs/COMPATIBILITY.md` и `docs/ARCHITECTURE.md` в исходном коде.
