# ФШ777 · 0.7.1 Desktop — рабочее пространство и текстовые блоки

Общий локальный графический редактор для **Windows x64**. Документы, слои, изображения, текст, контуры, маски, коррекции и операции доступны независимо друг от друга.

## Скачать

- **FSH777-0.7.1-Windows-x64.exe** — установщик.
- **FSH777-0.7.1-Windows-x64.zip** — распаковать всю папку и запустить `ФШ 777.exe`.
- **SHA256SUMS.txt** — контрольные суммы.

Для запуска не нужны Node.js, Arena, отдельный браузер или сервер. Автообновления нет. Сборка тестовая и не подписана издателем: проверяй источник и хеши, не отключай защиту Windows. Перед обновлением сохрани важные PSD и экспортируй операции. Старые выпуски не перезаписываются.

## Рабочее пространство

- Единые общие названия панелей, свойств и методов.
- Главная содержит создание/открытие документов, недавние файлы и восстановление, без отдельного учебного задания.
- Среды **«Стандартная», «Свойства», «Текстовые блоки»**. Прежние размеры, положение и выбранные вкладки мигрируют без сброса настроек.
- Восстановление: **«Плавный фон» / «Повторяющаяся текстура»**. Размещение под верхним текстовым стеком включается пользователем явно.

## Панель «Тексты»

- Переиспользуемые текстовые блоки с содержимым, метками и состояниями **«Черновик», «Готово», «Проверено»**.
- Исходный текст и заметка необязательны и находятся в раскрывающихся дополнительных полях.
- **«Из слоя»** копирует текст в новый блок, не изменяя исходный слой. Блок можно разместить на холсте, вставить в выбранный текст или связать со слоем. Обновление выполняется только по кнопке.
- Текстовый слой и его связь создаются одной отменяемой операцией. Удаление записи не удаляет пользовательский слой.
- Обмен — **`.777texts.json`**. Старые данные и формат обмена читаются с сохранением содержимого и состояний; импорт отдельного списка не наследует чужие IDs/связи.
- Новые рамки по умолчанию прямоугольные. Уже сохранённые овальные рамки остаются прежними.

Сам список сохраняется как дополнительные метаданные PSD/автокопии. Созданные текстовые слои остаются настоящими native TypeLayer, не картинками.

## Совместимость и точность

- Неизменённый старый PSD с прежними текстовыми метаданными возвращается побайтно. После правки записывается текущая схема; неоднозначные смешанные списки отклоняются вместо потери данных.
- Ресурс совместимости используется только для соответствующих ранее сохранённых пользовательских документов. Новая главная его не загружает и не предлагает; пользовательские изображения не подменяются.
- Исправлено квантование цвета прозрачного кеша обычного однотонного текста. Цветные глифы и сложные mask/warp/blur/FX-варианты не перекрашиваются этим упрощением. Native type data сохранены.
- Интеграционные проверки восстановления/связанных текстов используют отдельную синтетическую фикстуру, которая не поставляется как демонстрация приложения.

## Сохранённый функционал

Перо/узлы P/A, 15 корректирующих типов, RGB-кривые/гистограмма, Gradient Map/Photo Filter/CUBE, экспорт цветового стека, числовые выражения, сложные выделения и Q, направляющие/сетка/компоновка, шесть фильтров на копии, кисть/штамп/заливка, J, запись операций, шрифты, вкладки и восстановление. **Ctrl+S → PSD**, `.777` — резервная копия.

## Проверки выпуска

Матрица: **265 unit / 29 файлов, 11 desktop security/IPC/font-probe, 119 production browser-сценариев, 35 независимых PSD-случаев**. Windows gate запускает исходный Electron и упакованный EXE; он проверяет файловый IPC, шрифты, текстовые блоки/восстановление, native PSD, контуры, коррекции, CUBE и историю.

**Photoshop/XnConvert и интерактивная установка NSIS отдельно не запускались.** Полная Adobe parity, произвольные ICC/CMYK/RAW/HDR, rich/path text, Generative Fill, плагины и полный набор Adobe FX не заявляются.
