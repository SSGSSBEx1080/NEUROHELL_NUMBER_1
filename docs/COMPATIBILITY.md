# Форматы и ограничения ФШ 777 · 0.2.0

## Собственный проект `.777`

JSON с собственными слоями, встроенными изображениями, текстом, трансформациями/перспективой, цветокоррекцией и стилями. Подходит для продолжения редактирования. История отмены, системный буфер и набор операций в проект не входят. Операции экспортируются отдельно как `.777actions.json`.

Автосохранение — последний проект в IndexedDB текущего профиля приложения/браузера. В Windows стандартный профиль — `%APPDATA%\FSH777`. Удаление/очистка профиля стирает автосохранение. Закрытие без ожидания сохранения может потерять последние изменения; скачанный `.777` — отдельная копия.

## PSD / PSB

| Содержимое | Импорт | Экспорт |
|---|---|---|
| RGB/градации серого, 8 бит | Да, в пределах бюджета | RGB, 8 бит |
| Растровые слои | Пиксели, имя, положение, видимость, непрозрачность | Отдельные слои с этими свойствами |
| Режимы наложения | Восемь поддерживаемых; остальные заменяются с предупреждением | Поддерживаемые режимы |
| Группы | Разворачиваются, имена получают путь группы | Иерархия групп не восстанавливается |
| Растровые маски | Применяются к пикселям | Отдельные маски не записываются |
| Обтравочные/векторные/составные маски | Неполная поддержка, предупреждение | Не восстанавливаются |
| Текст | Растр для внешнего вида; доступно извлечение текста с заменой шрифта | Простой текст получает текстовые метаданные; сложные стили, отражение, фильтры, перспектива — растр |
| Смарт-объекты | Доступный растровый предпросмотр | Не восстанавливаются |
| Стили | Базовые обводка/тень/свечение/цветовое наложение — приблизительно | Запекаются в пиксели; не нативные редактируемые Adobe fx |
| Фигуры/перспектива | Доступные пиксели слоя | Растровые слои |
| Корректирующие слои без пикселей | Не воспроизводятся; предупреждение | Собственная цветокоррекция запекается |
| Композит исходного файла | Добавляется отдельным слоем для сравнения, если остаётся место | Новый композит рендерится из текущего документа |
| ICC-профили, печатные метаданные | Не применяются/не сохраняются | Не переносятся; рабочее пространство sRGB |
| Пиксели за холстом | Поддерживаемые растровые данные могут сохраниться в слое | Обрезаются по границе холста |

Изолированное смешивание групп, шрифтовая метрика, сложные эффекты и исходные цветовые профили могут изменить внешний вид. Переключай глаз слоя **«Оригинал · композит для сравнения»**, чтобы сравнить результат; не оставляй его включённым поверх своих изменений. Слой сравнения также расходует бюджет растров.

Декодер — ag-psd (MIT), дополненный проверкой заголовка, лимитами и отдельным worker. Проверяется фактический PSD v1/PSB v2 round-trip, а не только имя файла. Это не сертификация Adobe и не гарантия поддержки любых Photoshop-файлов. Реальные пользовательские PSD/PSB нужны для дальнейшего расширения тестового набора.

## Операции `.atn`

Ограниченный data-only reader ATN v16. Наборы и шаги отображаются в панели «Операции» с отчётом о поддержке. Поддерживаются только распознанные безопасные команды из белого списка: например, инверсия, обесцвечивание, дублирование/удаление выбранного слоя и определённые параметры цветокоррекции.

**Неподдерживаемый включённый шаг блокирует операцию целиком.** Неизвестные команды не пропускаются молча; скрипты, JSX, плагины, внешние файлы и произвольные команды не выполняются. Набор выполняется как одно действие истории. Полного рекордера всех пользовательских действий нет: сохранение собственного пресета фиксирует текущую цветокоррекцию слоя.

Коммерческие наборы, зависящие от выделений, масок, конкретных имён слоёв, плагинов и диалогов Photoshop, часто не смогут выполниться в этой версии.

## Растровый экспорт

- **PNG:** без потерь, прозрачный холст или непрозрачная подложка. Отключённая прозрачность на прозрачном исходном холсте даёт белую подложку.
- **JPG:** без альфа-канала. Прозрачные участки исходного холста заполняются белым; качество настраивается.
- **WebP:** поддерживает прозрачность; качество настраивается, экспорт с потерями.
- Масштаб 0.5×/1×/2×. Двойной масштаб недоступен, если результат превышает 32 Мп. Растрирование не восстанавливает отсутствующие детали исходного изображения.
- Экспорт отражает **видимые** слои и их фактические пиксели; состояние текущего выделения не ограничивает экспорт.

## Защита ресурсов

| Ресурс | Лимит |
|---|---|
| Холст | 4096 × 4096 px |
| Слои | 100 |
| История | 30 действий; не сохраняется в `.777` |
| Уникальные активные растровые источники | 24 Мп суммарно, включая скрытые слои |
| Входной PNG/JPEG/WebP | До 25 МБ файла и 32 Мп до декодирования; большие стороны уменьшаются до 4096 |
| Проект `.777` | До 50 МБ при открытии |
| PSD/PSB | До 80 МБ файла, 192 МиБ декодированных растров |
| Один декодированный слой PSD | До 8192 px по стороне и 24 Мп |
| Набор операций | До 8 МБ файла и 100 операций вместе с уже загруженными |
| Кэш изображений / стилей / перспективы | 128 / 64 / 64 МиБ |

Бюджеты нужны для предсказуемой работы, но не являются строгим лимитом всей оперативной памяти процесса: история, строки изображений, браузерный движок и промежуточные буферы тоже занимают память. PSB не означает поддержку многогигабайтных документов. Сложные проекты могут потребовать уменьшения изображений или объединения слоёв.

## Что не обещается

Нет полной совместимости с Adobe, нулевого числа ошибок, юридической неуязвимости или доказанного превосходства в скорости над Photoshop. Не реализованы RAW, CMYK/Lab/индексированные документы, 16/32-битный рабочий процесс, видео/3D, плагины, нейросетевой контент, произвольные контуры и полная редактируемость Adobe-масок/смарт-объектов. Ошибка/ограничение должны показываться пользователю, а не выдавать имитацию выполненной операции.
